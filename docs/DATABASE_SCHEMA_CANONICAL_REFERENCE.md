## 📋 Complete Database Schema

### **1. ARTICLES TABLE**
**Source:** `001_create_initial_tables.sql` + incremental migrations (002-010)

```sql
CREATE TABLE IF NOT EXISTS articles (
    id SERIAL PRIMARY KEY,
    
    -- Core Content
    title VARCHAR(500) NOT NULL,
    content TEXT,
    summary TEXT,
    body TEXT,
    author VARCHAR(255),
    
    -- URLs & Identification
    source_url VARCHAR(1000) UNIQUE,
    normalized_url VARCHAR(1000),
    url_hash VARCHAR(128),
    url_hash_algo VARCHAR(32) DEFAULT 'sha256',
    
    -- Metadata
    published_at TIMESTAMP,
    publication_date TIMESTAMPTZ,
    language VARCHAR(16),
    section VARCHAR(255),
    tags TEXT,
    authors JSONB,
    
    -- Content Processing
    extraction_confidence DECIMAL(4,3),
    extraction_metadata JSONB,
    structured_metadata JSONB,
    raw_html_ref VARCHAR(1024),
    
    -- Sentiment & Analysis
    sentiment_score DECIMAL(3,2),
    sentiment_label VARCHAR(20),
    sentiment_reasoning TEXT,
    
    -- Bias Analysis
    bias_score DECIMAL(3,2),
    bias_label VARCHAR(20),
    bias_explanation TEXT,
    bias_detected_entities TEXT,
    
    -- Synthesis
    synthesis_status VARCHAR(50),
    synthesized_summary TEXT,
    synthesis_confidence DECIMAL(3,2),
    synthesis_source VARCHAR(255),
    
    -- Editorial Scoring
    score FLOAT,
    evidence TEXT,
    is_featured BOOLEAN DEFAULT FALSE,
    category VARCHAR(20),
    
    -- Status Tracking
    analyzed TINYINT(1) DEFAULT 0,
    embedded BOOLEAN DEFAULT 0,
    needs_review BOOLEAN DEFAULT FALSE,
    review_reasons JSONB,
    
    -- Source Tracking
    source_id INT DEFAULT NULL,
    
    -- Timestamps
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    collection_timestamp TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    
    -- Embeddings (if using inline storage)
    embedding DOUBLE PRECISION[]
);

-- Key Indexes:
CREATE INDEX IF NOT EXISTS idx_articles_published_at ON articles(published_at);
CREATE INDEX IF NOT EXISTS idx_articles_author ON articles(author);
CREATE INDEX IF NOT EXISTS idx_articles_source_url ON articles(source_url);
CREATE UNIQUE INDEX IF NOT EXISTS idx_articles_normalized_url ON articles(normalized_url);
CREATE UNIQUE INDEX IF NOT EXISTS idx_articles_url_hash ON articles(url_hash);
CREATE INDEX IF NOT EXISTS idx_articles_publication_date ON articles(publication_date);
```

**Field Count:** 50+ columns

### **2. SOURCES TABLE**
**Source:** `009_create_sources_table.sql`

```sql
CREATE TABLE IF NOT EXISTS sources (
    id INT AUTO_INCREMENT PRIMARY KEY,
    
    -- Identification
    domain VARCHAR(255) UNIQUE,
    url VARCHAR(500),
    name VARCHAR(255),
    description TEXT,
    
    -- Geographic & Language
    country VARCHAR(10),
    language VARCHAR(10),
    
    -- Access Control
    paywall BOOLEAN DEFAULT FALSE,
    paywall_type VARCHAR(50),
    last_verified DATETIME,
    
    -- Metadata
    metadata JSON,
    
    -- Timestamps
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- Indexes:
CREATE INDEX IF NOT EXISTS idx_sources_domain ON sources(domain);
CREATE INDEX IF NOT EXISTS idx_sources_country_lang ON sources(country, language);
```

## 🔑 Key Column Definitions

### **Common Columns** (Present in Most Tables)

| Column | Type | Purpose |
|--------|------|---------|
| `id` | INT/SERIAL | Primary key (auto-increment) |
| `created_at` | TIMESTAMP | Record creation time |
| `updated_at` | TIMESTAMP | Last update time |
| `status` | VARCHAR(50) | Processing status |
| `metadata` | JSON | Flexible metadata storage |

### **Article-Specific Key Columns**

| Column | Type | Purpose | Default |
|--------|------|---------|---------|
| `title` | VARCHAR(500) | Article headline | NOT NULL |
| `body` / `content` | TEXT | Full article text | NULL |
| `summary` | TEXT | Brief summary | NULL |
| `source_url` | VARCHAR(1000) | Original article URL | UNIQUE |
| `normalized_url` | VARCHAR(1000) | Standardized URL | NULL |
| `author` | VARCHAR(255) | Article author name | NULL |
| `published_at` | TIMESTAMP | Publication date | NULL |
| `language` | VARCHAR(16) | ISO 639-1 code | NULL |
| `category` | VARCHAR(20) | News category | 'world' |
| `score` | FLOAT | Editorial quality score | NULL |
| `embedded` | BOOLEAN | ChromaDB embedded flag | 0 |
| `analyzed` | TINYINT(1) | NLP analysis complete flag | 0 |
| `sentiment_score` | DECIMAL(3,2) | -1.0 to 1.0 sentiment | NULL |
| `bias_score` | DECIMAL(3,2) | 0.0 to 1.0 bias level | NULL |

## ⚠️ Known Schema Issues & Fixes

### Fixed Issues
- ✅ **Issue:** `crawler_jobs.result` was TEXT (64KB limit)
  - **Fix:** Migration 010 widened to LONGTEXT (4GB limit)
  - **Impact:** Large batch crawls (600+ articles) now supported
  
- ✅ **Issue:** No way to link articles back to sources
  - **Fix:** Migration 010 added `articles.source_id` column
  - **Impact:** Better source attribution tracking

- ✅ **Issue:** No flag for articles needing NLP analysis
  - **Fix:** Migration 010 added `articles.analyzed` flag
  - **Impact:** Faster identification of unprocessed articles
